# Changelog

What changed in each Amethyst release. Versions below 1.0.0 are beta versions, free under the [Amethyst License](LICENSE) until 30 days after 1.0.0 is out. From then on every version needs a paid license, and a paid license covers Amethyst only while it is paid for.

## 0.2.7

- Safer chats: while "chats answer other chats' permission asks" is off, other chats and outside agents can send only `/compact`, `/model`, `/effort` and `/fast`. Any other slash command from them is refused, so they can't change a chat's mode or permissions. Your own messages work as before.
- Amethyst's code and releases now live at [github.com/devdelion-one/Amethyst](https://github.com/devdelion-one/Amethyst); updates keep working as before.

## The first public beta

The first public beta.

- Amethyst is source available: its whole source code is in this repository.
- The installer shows the license, and you accept it before installing.
- Amethyst updates itself from this public repository.
- THIRD-PARTY-NOTICES.txt lists the licenses of the open-source parts Amethyst includes.
