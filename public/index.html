How Amethyst works
Everything local

Chats, layouts, and project state stay on your PC. Code goes only to the agent you choose.

No telemetry

No background tracking or usage analytics. Your workspace stays private.

Optimized for scale

Built to keep many parallel agents, terminals, and projects responsive in one window.

Your own accounts

Sign in with the Claude, Codex, Antigravity, Cursor, and Copilot plans or API keys you already use.

Source available

Readable TypeScript files ship with the installer so you can inspect the code or build it yourself.

Chats survive restarts

Close Amethyst anytime; every chat comes back asleep and picks up right where you left off.
