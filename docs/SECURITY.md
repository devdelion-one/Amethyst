# Security

If you find a security problem in Amethyst, don't post it in a public channel or issue. Report it privately:

- send a direct message to the developer on the [Amethyst Discord](https://discord.gg/yppAbHmMXG), or
- email support@amethyst.run.

Include the Amethyst version, what someone could do with the problem, and the steps to show it. I'll confirm that I
got your report and tell you when a fix is released.

Security problems in an agent itself (Claude Code, the Codex CLI or the Antigravity CLI) go to its provider: Anthropic,
OpenAI or Google.
