# Support

Ask questions and report bugs on the [Amethyst Discord](https://discord.gg/yppAbHmMXG): questions in **#help**, bugs in
**#bug-reports**, ideas in **#feedback**. Check **#known-issues** first, the problem may already be listed there.

## A good bug report

- **Amethyst version**: settings show it.
- **Windows version**: Windows 10 or 11.
- **Agent involved**, if any: Claude, Codex or Antigravity.
- **Steps to reproduce**, numbered.
- **What you expected** and **what happened** instead.
- **How often**: every time, sometimes or once.
- **Logs or screenshots**, if you have them.

Before posting logs or screenshots, remove API keys, access tokens, passwords, private code and anything else you
don't want public.

Problems with an agent itself (Claude Code, the Codex CLI or the Antigravity CLI) go to its provider. Report them here
too if you're not sure, and I'll tell you.

Security problems don't go in public channels: see [SECURITY.md](SECURITY.md).
