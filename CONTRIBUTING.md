# Contributing

Issues, bug reports and ideas are welcome, here or on the [Amethyst Discord](https://discord.gg/yppAbHmMXG).

Code pull requests aren't accepted for now. You may keep a fork to show a change you'd like, as [LICENSE](LICENSE)
allows, and point to it in an issue.

Security problems don't go in public issues: see [docs/SECURITY.md](docs/SECURITY.md).
